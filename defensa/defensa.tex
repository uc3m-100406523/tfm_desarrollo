\subsection{Motivaciones}

\begin{itemize}
	\item {
		Quinta generación de comunicaciones móviles (5G).
		\begin{itemize}
			\item \textit{3rd Generation Partnership Project} (3GPP).
			\item Casos de uso.
			\item {
				Desarrollo de aplicaciones.
				\begin{itemize}
					\item Despliegues existentes.
					\item Exhaustivos ensayos y metodologías fiables.
				\end{itemize}
			}
			\item {
				Desarrollo de los despliegues.
				\begin{itemize}
					\item Ajuste de varios elementos.
					\item Interfaz de radio de 5G (NR).
				\end{itemize}
			}
		\end{itemize}
	}
	\item {
		Nuevos casos de uso.
		\begin{itemize}
			\item XR, VR, AR. $\rightarrow$ Baja latencia.
			\item Comunicaciones en entornos vehiculares (C-V2X). $\rightarrow$ Baja latencia.
			\item Inconvenientes para cobre, fibra óptica, cable coaxial, etc. $\rightarrow$ Cobertura de gran ancho de banda.
		\end{itemize}
	}
\end{itemize}

% SUBSECCIÓN
\subsection{Estado de la cuestión}

\begin{itemize}
Simuladores de RAN.
	Probar configuraciones de red.
	Diseñar tras acotar unas prestaciones.

Emuladores de RAN.
	Probar configuraciones de red.
	Diseñar tras acotar unas prestaciones.
	Probar aplicaciones para 5G que se ejecutan en tiempo real.

Emulador \textit{FikoRE}.
	Desarrollada por \textit{Nokia} en colaboración con la UC3M.
	Experimentación a nivel de aplicación.
	Usuarios de distintas disciplinas pueden utilizarlo.
	Permite su modificación de manera sencilla.
	Buenas prestaciones a nivel de
		tráfico soportado
		número de instancias
		escalabilidad
		precisión
	Permite analizar casos de uso y despliegues de red con un alto nivel de realismo.

Planificación de paquetes.
	Asignación de los recursos de radio.
	Literatura extensa.
	Necesidad de validación.
		Despliegue real de 5G caros, poco flexible.
		Emulador barato, se puede reajustar para probar estrategias.

Comunicaciones en entornos vehiculares (C-V2X).
	Importancia
		La automoción es de los sectores más impactados.
		La automoción es fundamental en la economía.
	Desarrollo
		Numerosas iniciativas de investigación.
		3GPP ya incluyó C-V2X entre sus prioridades.
		\textit{FikoRE} puede representar escenarios de C-V2X.

Otros casos de uso.
	servicio URLLC comunicaciones fiables y de muy baja latencia aplicaciones que dependen de la seguridad.
	AR/VR/MR dependen por completo de 5G.
	Se pueden recrear con \textit{FikoRE}.

% SUBSECCIÓN
\subsection{Estructura del trabajo}

Objetivo evaluar despliegues de 5G y de aplicaciones para 5G mediante el emulador \textit{FikoRE}.

Sección ``Interfaz de radio de 5G''.
	Descripción de la interfaz de radio de 5G.
	Conceptos de redes móviles.
	Simulación y emulación de la interfaz de radio.

Sección ``Emulador \textit{FikoRE}''.
	Características más importantes.
	Procedimientos para emular la interfaz de radio.
	Capacidades de emulación.

Sección ``Caso de uso: planificación de paquetes (\textit{packet scheduling})''.
	Estudio y diseño de planificación de paquetes
	Varias simulaciones
	Conclusiones sobre el diseño del planificador de paquetes

Sección ``Caso de uso: comunicaciones celulares en entornos vehiculares (C-V2X)''.
	Estudio y diseño para C-V2X.
	Varias simulaciones.
	Conclusiones sobre el diseño para C-V2X y sobre su viabilidad.

Sección ``Conclusiones''.
	Se recopilan las conclusiones del trabajo.
